# نطاق العملية وتوجيه الكمية — بداية المحطة2

## التنفيذ

- إضافة `WarehouseOperationScope` بمنشئ خاص؛ يُحلّ من اتصال القاعدة وسياقها ومخزن نشط في نفس المؤسسة والفرع. يحتفظ بالهوية الثابتة ولا يغير سياق القاعدة.
- يعاد التحقق داخل معاملة الكتابة، بما في ذلك تعطيل المخزن بعد اختياره وتغيير الهوية واستخدام اتصال قاعدة آخر. النطاق ليس تفويض صلاحية ولا استحقاق اشتراك.
- `StockService.adjustStock` يقبل نطاقًا اختياريًا؛ غيابه يحافظ على الرئيسي. تحديث الكمية يستخدم معامل SQL مربوطًا بمعرف المخزن، مع تحقق تبعية المتغير للصنف.
- حركة الصنف البسيط تختار صفه التشغيلي النشط الوحيد. حركة المخزن الإضافي لا تكتب رصيد الأب أو المتغير القديم؛ تجميع مرآة الأب يُنفذ للمخزن الرئيسي فقط.
- غياب صف الرصيد يتوقف دون إنشاء رصيد تخميني أو الرجوع للرئيسي. التهيئة المحاسبية لمخزن جديد ستنفذ ضمن S2-06.
- لا تغيير للمخطط أو البيانات عند الترقية، ولا واجهة أو مسار LAN جديد. تكاليف ودفعات وترحيل مستندات المخازن الإضافية لم تُفعّل بعد.
