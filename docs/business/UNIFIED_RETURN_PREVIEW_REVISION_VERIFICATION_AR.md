# المحطة الثانية — ربط معاينة المرتجعات بمراجعة الضريبة

## التنفيذ

- تعيد `priceAdjustmentItems` كائن `UnifiedAdjustmentQuote` داخليًا يحتفظ باتصال القاعدة، ونوع المرتجع، ومدخلات البنود، وقواعد ضريبة الأصناف، ولقطة سياسة الفرع. تحتفظ الواجهة بحقلي `pricing` و`taxInclusive`.
- تُقرأ السياسة وبيانات الأصناف داخل معاملة قراءة واحدة. السياسة الدائمة مقدمة على ذاكرة الإعدادات؛ فقدان السياسة في خدمة مهيأة للتخزين الدائم يرفض المعاينة بدل الرجوع إلى تفضيلات الجهاز.
- يقبل مسارا ترحيل مرتجع البيع والشراء `expectedAdjustmentQuote`. يجري التحقق وإعادة التسعير داخل معاملة الترحيل وقبل أي كتابة للمستندات أو القيود. تختلف مراجعة السياسة حتى إذا عادت القيم إلى حالتها السابقة.
- يُرفض تغير نوع المرتجع أو اتصال القاعدة أو البنود أو الكميات أو الأسعار أو قواعد ضريبة الأصناف. لا يُستخدم الكائن لإثبات الصلاحية.
- المستدعون السابقون دون معاينة يستمرون بالتسعير وقت الترحيل. المرتجعات المرتبطة تستخدم حسابات الفاتورة الأصلية؛ السياسة الحالية تخص جزء التسوية فقط.

## التحقق

- نجحت 114 حالة في ملفات المرتجعات الموحّدة، ومرجع المورد، وحدود المرتجعات بعد التسويات، وقراءات مخزون وتاريخ المرتجعات حسب المخزن، وإعدادات الضرائب ومخزن مراجعاتها.
- منها 10 حالات جديدة: رفض تغييرات السياسة والصنف والكمية ونوع المرتجع على جانبي البيع والشراء دون تغيير المستندات أو الأطراف أو القيود أو المنتجات؛ قراءة السياسة الدائمة رغم تقادم الذاكرة؛ رفض فقدان السياسة.
- اختبارات النجاح الستة عشر للضرائب تقدم الآن المعاينة عند الترحيل، وتشمل الشمول والإعفاء والتعطيل وتجاوز معدل الصنف والأصناف ذات المتغيرات.
- `flutter analyze`: بلا ملاحظات. `git diff --check` للملفات المعدلة: ناجح.
- سجل الاختبارات: `/tmp/tapix-return-quote-regressions.log`؛ سجل التحليل: `/tmp/tapix-return-quote-analyze-final.log`.

## الحدود المتبقية

هذه حماية داخلية لخدمة المرتجعات الموحّدة؛ لم تُربط بعد بنماذج الواجهات أو بروتوكول LAN. قبول المعاينة اختياري للتوافق مع المستدعين السابقين. ليست ضمانًا لمنع تقادم معاينات جميع المستندات. يلزم ربط واجهات البيع والشراء والتسويات وبروتوكول الشبكة، مع الحفاظ على إعادة الطلبات المترحلة سابقًا دون تكرارها، ومعالجة رسالة تحديث المعاينة باللغات الثلاث.

لا تغيير في مخطط القاعدة أو الاشتراكات أو بيانات الهاتف. لم تُعد مجموعة الاختبارات الكاملة في هذه الخطوة؛ اقتصر التشغيل على الاختبارات المتأثرة. المحطة الثانية مفتوحة، وبناء Linux وAndroid في نهايتها.
