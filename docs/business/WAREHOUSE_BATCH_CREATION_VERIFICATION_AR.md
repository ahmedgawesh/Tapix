# إنشاء الدفعات بنطاق مخزن ثابت — S2-04

21 سبتمبر2026. مخطط القاعدة10088.

## التنفيذ

- عمود اختياري `product_batches.warehouse_id` يحدد مسار إنشاء الدفعة. تبقى سجلات `business_document_locations` مصدر الموقع التاريخي. الصفوف القديمة تحتفظ بقيمة NULL وبمواقعها التاريخية المسجلة.
- عند الإنشاء، تسجل SQLite موقع الدفعة في نفس بيان إدراجها؛ أي فشل في الموقع يتراجع عن الدفعة أيضًا. المخزن الصريح يجب أن يكون نشطًا ومن نفس المؤسسة والفرع المحلي.
- منع تغيير موقع المستند مستمر، وأُضيف منع تغيير عمود مسار الدفعة، بما فيه إعادته إلى NULL. لا تغيير لسياق القاعدة العام ولا نقل دفعة قائمة بهذه الآلية.
- `createOpeningBatch` و`createBatchFromPurchase` يقبلان نطاق العملية. نطاق غائب يحافظ على الرئيسي. بند شراء تابع للرئيسي لا يستطيع إنشاء دفعة في مخزن إضافي؛ التحقق في الخدمة وفي قاعدة البيانات للدفعات ذات المسار الإضافي.
- شرط التشغيل الرئيسي للمستندات الأخرى باقٍ. فتح مواقع البيع والشراء والتسويات والقيود وربطها ليس جزءًا مكتملًا بهذه الدفعة.

## الترقية والتحقق

- إضافة العمود وتركيب قيود المواقع ضمن معاملة الترقية نفسها. لا تعديل للكميات والتكاليف أو إعادة نسبة المواقع القائمة.
- تحديث اختبارات الإصدار الحالي إلى10088 دون تغيير أرقام مصادر ملفات الترقية القديمة.
- توليد Drift الكامل عبر `dart run build_runner build` لتجنب ترك ملفات مولدة غير متسقة.
- 7 حالات جديدة: إنشاء دفعة إضافية واستهلاكها بتكلفتها، توافق الرئيسي، منع إعادة النسبة، تراجع الإنشاء إذا فشل الموقع، رفض مخزن معطل عند الإدراج المباشر، رفض مصدر شراء في المخزن الآخر، وترقية ملف10087 مع حفظ المواقع والكميات والتكاليف.
- اختبار الملف القديم يتعمد إفشال الترقية بتعارض اسم فهرس؛ يتحقق من رجوع العمود والإصدار، ثم يعيد المحاولة بنجاح بعد إزالة التعارض.
- الاختبارات المركزة الأولى:21 ناجحة. المجموعة الموسعة: **894 اختبارًا ناجحًا**، والتحليل النهائي دون ملاحظات و`git diff --check` ناجح. المجموعة الكاملة بعد تغيير نماذج Drift المشتركة: **3214 اختبارًا ناجحًا**. لم يُشغّل بناء منصات في هذه الدفعة.

## المتبقي

أصبح إنشاء الدفعة بالنطاق ممكنًا داخل الخدمة، لكنه ليس إنشاء افتتاحي محاسبي مكتملًا بمفرده. يتبقى تمرير نطاق المستندات والقيود ومطابقة الرصيد والتقييم وإنشاء أرصدة المخزن وفق S2-05 وS2-06، وتكامل إعادة التقييم ضمن S2-04. لا تُفتح واجهة التشغيل الإضافي للعملاء بهذه الدفعة. البناء عند نهاية المحطة2 فقط؛ لا تثبيت على الهاتف أو استبدال قاعدته.
